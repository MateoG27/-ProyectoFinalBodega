# Reservas USFQ

**Plataforma Web de Reservas de Equipos y Espacios** de la facultad.
Integrantes: Andrés Merino, Mateo Gordon, Pablo Vargas.

Sistema web para que estudiantes y profesores reserven equipos y espacios, y para que el administrador apruebe y controle el inventario.
